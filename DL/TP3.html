01 — Principe

Apprendre le normal, signaler l'inattendu

On ne dispose pas d'images de défauts annotées. L'auto-encodeur résout ce problème en apprenant uniquement sur des pièces saines : il compresse l'image vers un espace latent compact, puis la reconstruit. Un défaut — jamais vu à l'entraînement — sera mal reconstruit. L'erreur de reconstruction devient le signal d'anomalie.

02 — Étape 1

Architecture de l'auto-encodeur

🔽 Encodeur — compression

enc1 · Conv2D(32, 3, s=2)128×128×32
enc2 · Conv2D(64, 3, s=2)64×64×64
enc3 · Conv2D(128, 3, s=2)32×32×128 ← goulot

🔼 Décodeur — reconstruction

dec1 · ConvTranspose(64, 3, s=2)64×64×64
dec2 · ConvTranspose(32, 3, s=2)128×128×32
dec3 · ConvTranspose(3, 3, s=2)256×256×3 · sigmoid
Piège central — ratio de compression

Entrée : 256×256×3 = 196 608 valeurs
Goulot : 32×32×128 = 131 072 valeurs
Ratio ≈ 1.5 — très proche de 1 !

Un ratio aussi faible permet au modèle d'apprendre une quasi-identité : il reconstruit les défauts aussi fidèlement que les pièces saines, ce qui annule le signal d'anomalie. Pour forcer une représentation vraiment compacte, il faudrait un ratio ≥ 4 (ex. réduire les filtres ou ajouter un MaxPool supplémentaire). 

from indusense.vision.model import build_autoencoder, compression_ratio

model = build_autoencoder(input_shape=(256, 256, 3), filters=(32, 64, 128))
model.summary()

ratio = compression_ratio(model)
print(f"Ratio : {ratio:.2f}")  # → 1.50  ⚠ trop proche de 1
03 — Étape 2

Entraînement

La cible est l'image elle-même — c'est l'astuce centrale de l'auto-encodeur : minimiser l'erreur de reconstruction sur les seules images saines.

Perte : MSE vs SSIM

MSE — Mean Squared Error

Pénalise les grandes erreurs de valeur de pixel. Dominé par les zones homogènes (fond noir). Rapide et stable.

loss="mse"
SSIM — Structural Similarity

Compare la structure locale, le contraste et la luminance. Plus sensible aux altérations de texture — mieux adapté à la détection de défauts fins.

loss=mse_ssim_loss(alpha=0.8)

Stratégie d'entraînement

1
Adam + EarlyStopping
lr=1e-3, patience=10 — arrêt si la val_loss ne s'améliore plus. restore_best_weights=True.
2
ReduceLROnPlateau
Divise le lr par 2 après 5 époques sans amélioration → convergence plus fine.
3
Augmentation sur X_train uniquement
Pipeline Albumentations (TP1) appliqué avant le fit. Doublé le dataset sain → moins de mémorisation.
4
Suivi MLflow
Params, métriques et checkpoint loggués automatiquement. mlflow ui dans DL/ pour visualiser.

04 — Étape 3

Score d'anomalie & calibration du seuil

Le score par image = MSE entre l'image et sa reconstruction. On calibre le seuil sur les images saines de validation uniquement (centile 99 ou moyenne + k·σ).

Distribution des scores — avant vs après seuil
Seuil
Saines (score faible)
Zone d'incertitude
Défauts (score élevé)
Arbitrage métier

Abaisser le seuil → plus de rappel (moins de défauts manqués) mais plus de fausses alertes (pièces saines rejetées). Le bon choix dépend du coût d'une panne manquée vs du coût d'un arrêt machine inutile.

from indusense.vision.anomaly import reconstruction_errors, calibrate_threshold

errors_val  = reconstruction_errors(model, X_val)
errors_test = reconstruction_errors(model, X_test)

# Calibré sur validation (images saines uniquement)
threshold = calibrate_threshold(errors_val, method="percentile", percentile=99)

Heatmaps & Évaluation

La carte d'erreur par pixel (MSE canal par canal) permet de localiser la zone suspecte. On la superpose au masque de vérité terrain pour vérifier qualitativement.

AUROC < 0.5 — pire que le hasard

Un AUROC = 0.5 correspond à un classifieur aléatoire. 0.465 signifie que les défauts ont une erreur de reconstruction plus faible que les pièces saines — le classement est inversé. Le modèle reconstruit les défauts aussi bien (voire mieux) que le normal : le piège du ratio ≈ 1.5 est confirmé en pratique. Inverser le seuil donnerait un AUROC de 0.535 — toujours médiocre. La solution est structurelle : resserrer le goulot.

TP=10 · TN=18 · FP=2 · FN=53 sur 83 images test.

06 — Analyse critique

Ce qui marche, ce qui échoue

✓ Ce qui fonctionne
  • Reconstruction fidèle des pièces saines
  • Défauts grossiers (broken_large) détectés
  • Heatmap localise qualitativement
  • Aucune annotation de défaut nécessaire
✗ Ce qui échoue — constaté en pratique
  • AUROC = 0.465 — en dessous du hasard (0.5)
  • Ratio ≈ 1.5 → identité quasi-parfaite : défauts reconstruits aussi bien que les sains
  • FN = 53 sur 63 défauts : 84 % des anomalies sont manquées
  • MSE dominé par le fond noir, insensible aux altérations de texture

Pour aller plus loin

L'auto-encodeur est un baseline pédagogique. En production, les méthodes basées sur des features pré-entraînées dominent :

  • PatchCore / PaDiM / SPADE — mémoire de features ResNet/WideResNet → AUROC > 98 % sans entraîner from scratch
  • FastFlow / CFLOW — Normalizing Flows sur features pré-entraînées
  • MemAE / Denoising AE — variantes de l'auto-encodeur qui atténuent le problème d'identité

Bibliothèque clé : anomalib (OpenVINO) — implémentations SOTA prêtes à l'emploi.
